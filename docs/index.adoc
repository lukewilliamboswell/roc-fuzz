[.lead]
roc-fuzz packages a typed Roc target and libFuzzer into one self-contained
executable. This manual covers target design, failure investigation, sustained
campaigns, CI evidence, release verification, and development of the platform.

.How to use this manual
****
New target author:: Start with <<fuzzing-your-first-roc-target>>.
Experienced fuzzing user:: Continue with <<advanced-fuzzing>> for generator
dispatch, allocation assertions, corpora, tuning, and raw libFuzzer options.
Downstream maintainer:: Read <<fuzzing-evidence-for-downstream-projects>> for
the report contract and bounded GitHub Actions pattern.
Release verifier:: Read <<release-bundle-provenance>>.
Platform contributor:: Read <<contributing-to-roc-fuzz>> for toolchains,
validation, packaging, and release behavior.
****
